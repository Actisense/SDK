## Contributing to the documentation

Before submitting documentation changes, run the automated checks (links,
internal references, public-API symbol drift):

```
python tools/docs-checks/check_docs.py
```

See [tools/docs-checks/README.md](tools/docs-checks/README.md) for details.
The same checks run in CI on every pull request.
